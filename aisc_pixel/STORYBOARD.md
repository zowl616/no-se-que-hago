# AISC — Pixel-Game Launch Spot (15s, 16:9)

The same AISC launch brief and metrics as the original spot, **re-skinned in 16-bit pixel-game style** and with **every word rendered deterministically** so there are zero misspellings.

- **Duration:** 15.000s (3 shots × 5.000s, hard cut)
- **Format:** 16:9, 1920×1080, 30 fps, H.264 yuv420p, faststart
- **Look:** NES/SNES title-screen art, jet-black + electric chartreuse `#D1FE17` on pure-white background, faint CRT scanlines, large-pixel chunkiness, no anti-aliasing
- **Type:** Press Start 2P (Google Fonts, OFL) rendered with PIL, composited via `ffmpeg overlay` — never generated by the AI

## Why no misspellings

The previous AISC launch spot relied on the image model to render typography. Diffusion models can still mis-letter long phrases, even on the strongest text models.

This pass takes the AI **out of the typography pipeline entirely**:

1. `nano_banana_2` is asked to produce *only* the pixel-art ornaments and empty typography zones — its prompts include explicit "DO NOT include any text, letters, numbers, words, glyphs, captions, or typography of any kind anywhere in the image" instructions.
2. `seedance_2_0` animates those text-free pixel scenes.
3. `aisc_pixel/build_overlays.py` uses Python + PIL with the bundled Press Start 2P TTF to rasterise every word at exact pixel positions into transparent 1920×1080 PNG title cards.
4. `ffmpeg` composites the PNG title cards over the Seedance clips with a 0.4s alpha fade-in (so the AI ornaments boot first, then the clean text lands on top).

Result: every glyph is byte-stable. Edit `build_overlays.py`, re-run, and the typography updates instantly with zero re-generation cost.

## Iterating

To change copy without spending any more Higgsfield credits:

```bash
$EDITOR aisc_pixel/build_overlays.py    # tweak the strings / sizes / positions
python3 aisc_pixel/build_overlays.py     # regenerate overlay PNGs
bash aisc_pixel/build_master.sh          # re-composite + re-export final master
```

To change the pixel-art ornaments, re-render one or more shots:

```bash
$EDITOR aisc_pixel/prompts/02_arcade_scoreboard_video.txt
higgsfield generate create seedance_2_0 \
  --prompt "$(cat aisc_pixel/prompts/02_arcade_scoreboard_video.txt)" \
  --aspect_ratio 16:9 --duration 5 --resolution 1080p --mode std \
  --start-image aisc_pixel/stills/02.png --wait
# replace aisc_pixel/clips/02.mp4 with the new download
bash aisc_pixel/build_master.sh
```
